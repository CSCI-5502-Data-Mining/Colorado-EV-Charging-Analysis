# Colorado EV Charging Access & Adoption

CSCI 5502 Data Mining semester group project by Eddie Strand and Snehal Bhatnagar.

## Project goal

This project investigates which socioeconomic, housing, and geographic characteristics are associated with EV adoption in Colorado and where public charging infrastructure may be insufficient relative to current or expected demand.

## Current research questions

1. Which socioeconomic, housing, and geographic characteristics are most strongly associated with EV adoption across Colorado?
2. Which Colorado areas have high EV adoption relative to the number of available public charging ports?
3. How does public EV charging availability differ across areas with different income and housing characteristics?
4. How does charging-port availability and density differ between rural and urban areas of Colorado?
5. Which Colorado areas show the greatest combination of expected charging demand and limited existing charging access?

## Planned data sources

- Atlas EV Hub — Colorado EV registration data
- U.S. DOE Alternative Fuels Data Center (AFDC)
- EValuateCO — selected Colorado charging usage data
- Colorado Information Marketplace — charging station locations
- U.S. Census American Community Survey (ACS)
